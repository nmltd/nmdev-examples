# Documentation publishing

Tutorial source is maintained in `docs/*.md` and `docs/tutorials/*.md`; benchmark guides are in `benchmark/site/`. The saved JMH archive supplies the charts and result tables.

```bash
python3 -m pip install -r scripts/requirements-docs.txt
python3 benchmark/scripts/publish-pages.py benchmark/results/2026-10-18-expanded
python3 scripts/check-site.py
```

The Documentation workflow runs these steps on documentation/example changes, builds pull requests without publishing, and deploys successful `main` builds to GitHub Pages. It requires no NM Dev package credentials or license because it renders saved documentation and results. Java examples must be validated separately against the licensed binary; docs CI does not claim to execute them.

The site root is the introduction. Interactive charts live at `benchmarks.html`. Generated HTML is a reviewable snapshot; the workflow rebuilds from source on every eligible change. Raw benchmark measurements are never regenerated by documentation publishing.
