# Wiki publishing

These Markdown files are ready for the separate GitHub Wiki repository. The live wiki is a separate Git repository and is not published merely by committing this folder. After an administrator enables Wiki and creates its first page, clone `https://github.com/nmltd/nmdev-examples.wiki.git`, copy Home.md, Getting-Started.md, the six tutorial pages and _Sidebar.md to its root, then commit and push. Do not copy this README into the wiki.

Until then, use the complete [versioned tutorial guide](../docs/README.md).
